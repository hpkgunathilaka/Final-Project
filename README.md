# Smart NGO Collaboration Platform

## 📌 Overview
The Smart NGO Collaboration Platform is a web-based system designed to connect Non-Governmental Organizations (NGOs) with technology partners such as students, developers, and professionals. The platform provides a centralized environment where NGOs can post project requirements and technology partners can discover, apply, and collaborate effectively.

This system aims to improve coordination, transparency, and efficiency by replacing manual communication methods with a structured digital solution.

## 🎯 Objectives
- To develop a centralized platform for NGO and technology partner collaboration
- To improve project coordination and communication
- To provide a structured environment for task management
- To enhance transparency and reduce administrative workload

## 👥 Users
- NGOs (Project creators and managers)
- Technology Partners (Developers / Volunteers)
- Admin (System management and monitoring)

## ⚙️ Technologies Used
- Backend: Node.js, Express.js
- Database: MongoDB
- Frontend: HTML, CSS, JavaScript
- Authentication: JSON Web Tokens (JWT)

## 🚀 Features
- User Registration and Login
- Role-Based Access Control
- Project Creation and Management
- Project Browsing and Application
- Task Assignment and Tracking
- Internal Messaging System
- Admin Dashboard

## 🛠️ Installation

1. Clone the repository
git clone https://github.com/your-username/ngo-collaboration-platform.git

2. Navigate to backend folder
cd backend

3. Install dependencies
npm install

4. Run the server
npm start

## 🔐 Environment Variables
Create a .env file in the backend folder and add:

PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
